# 🚀 AstroQuest – Junior Astronaut Mission Simulator

**Explore. Build. Survive. Discover.**

AstroQuest is an interactive 3D educational space exploration and planetary settlement simulator designed to introduce students to the challenges of establishing sustainable human habitats beyond Earth.

Players take on the role of mission commanders and make strategic decisions to establish and maintain settlements on the Moon and Mars while managing limited resources and responding to environmental challenges.

## 🌌 Project Overview

AstroQuest combines 3D visualization, interactive gameplay and STEM-based learning to create an engaging planetary exploration experience.

Players must manage essential survival resources, construct infrastructure and make decisions that affect the sustainability of their settlements.

### Key Features

- **3D Planetary Exploration:** Explore immersive lunar and Martian environments.
- **Resource Management:** Monitor power, oxygen, water, food and construction materials.
- **Base Construction:** Build essential infrastructure to support human settlements.
- **Environmental Challenges:** Respond to planetary conditions and unexpected events.
- **Mission-Based Gameplay:** Complete objectives through strategic planning and resource allocation.
- **Educational Experience:** Learn about planetary science, engineering and the challenges of human space exploration.

## 🏗️ Infrastructure & Resources

The simulation includes various structures and resource-management systems:

| Structure | Purpose |
|---|---|
| Solar Arrays | Generate electrical power |
| Greenhouses | Support food production |
| Ice Extractors | Obtain water resources from available ice deposits |
| Oxygen Generators | Support life-support requirements |
| Radiation Shielding | Protect settlement infrastructure |
| Mining Systems | Obtain construction resources |
| Habitats | Provide living spaces for the crew |

- **Build Tool:** Vite
- **Styling:** CSS / Tailwind CSS
- **UI Components:** Radix UI, Lucide React
- **3D Assets:** GLTF / GLB models and textures

## 💻 Getting Started

You can run AstroQuest locally on your computer.

### Prerequisites

- Node.js (LTS recommended)
- npm
- Git (optional)

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Directory

```bash
cd AstroQuest
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to access AstroQuest.

### 5. Build for Production

```bash
npm run build
```

## 📁 Project Architecture

The project is organized into several major components:

- `src/` – Main application source code.
- `src/lib/` – Simulation logic and resource-management systems.
- `src/scene/` – 3D planetary environments, terrain and structures.
- `src/assets/` – Project models, textures and other visual assets.
- `public/` – Public static assets.
